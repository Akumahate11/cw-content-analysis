# CW｜红笔改稿

> 用高低赞对标，逐句诊断你的内容稿。

很多 AI 内容分析看起来很有道理：开头要抓人、节奏要紧凑、结果要前置。但你拿着这些建议回去改自己的稿子，往往还是不知道具体该动哪一句，也不知道自己改得对不对。

`CW｜红笔改稿` 不只给一条笼统的结论。它先建立“好稿在这个位置应该长什么样”的标本，再把你的原句、高赞参考和观众此刻的期待放在一起，告诉你：**这句原本该完成什么任务、它为什么没有完成、参考内容在同一位置怎么处理，以及你最小能怎么改。**

它不承诺制造爆款，也不把 AI 改稿当成最终答案。目标是让你拿回判断力，而不是被 AI 牵着鼻子走。

## 它实际交付什么

对于一篇已经写完、或已经发布但数据不理想的稿子，核心交付是两份独立 Markdown：

1. `CW｜{稿件名}_诊断报告.md`：连续文字呈现的总体诊断，不使用表格；
2. `CW｜{稿件名}_全文红笔批改表.md`：从头到尾覆盖原稿的逐句对照表。

第一份先告诉你问题可能在哪些层，第二份才让你看见每一句具体怎么改：

| 你会看到什么 | 它回答的问题 |
| --- | --- |
| 七维前期诊断 | 需求、承诺、主线、交付、门槛、账号承接、样本和数据，哪些是事实、哪些只是待验证假设？ |
| 高样本标本 | 好稿在开头、第一次答案、转折、证据等关键位置，完整原句到底怎么写？ |
| 用户完整原句 | 你究竟写了什么，而不是被摘要后的意思 |
| 这句原本任务 | 这句话是在承诺、解释、转折、举证，还是推动行动？ |
| 观众已知 / 等待 / 反驳 | 观众此刻为什么会继续看、犹豫或划走？ |
| 参考完整原句 | 高样本池在同一个叙事位置到底怎么说？ |
| 功能差异与证据 | 两句话的差别究竟发生在哪里？ |
| 最小修改动作 | 删除、合并、前移、后移、补证据，或保留原话 |

它不会用“增强共鸣”“节奏更好”这类不指向原句、证据和具体动作的话来糊弄你。

## 适合谁

- 你写完一篇稿，却没有能力判断它到底好不好；
- 内容发出后数据不理想，知道有问题，却不知道该改哪里；
- 你希望借 AI 学会改稿，而不只想让 AI 一键代写；
- 你有一批想学习的高赞内容，但不会把“它为什么好”落实到自己的稿子上。

## 怎么使用

### 1. 红笔改稿：最直接的入口

给出你的完整稿件；如果已经发布，也附上数据和你的观察。再提供至少 5 篇高赞样本的完整逐字稿和可用数据。

Skill 会先做七维前期诊断，再建立好样本标本；最后才把你的原稿从头到尾逐句映射。没有可对应的高样本原句时，它必须标注比较缺口，不能把 AI 的猜测说成确定结论。

### 2. 拆对标：先建立判断标准

如果还没写稿，先给你想做的方向，再准备：

- 至少 5 篇高赞样本，用来提炼稳定的表达、交付和观看路径规律；
- 你自己的低赞稿，用来与高样本池逐句对照。

跨题材样本可以比较结构、交付和证据，但不能冒充细分赛道结论。

### 3. 写稿、盲测和发布后复盘

在对标和红笔批改之外，它还可以：

- 只有选题时，直接试写，或先提问收集你的真实经历与素材再写；
- 对最终稿、封面、标题和时长做发布前盲测；
- 将盲测与真实 24h / 7d / 30d 数据对照，逐步校准判断规则。

## 两种改稿方式

- **学习模式**：先看逐句批改，自己改一版，再提交二次批改。适合想真正练出判断力的人。
- **效率模式**：在逐句批改后获得一版备选改稿，并附上每项改动依据。适合需要尽快得到一版可继续修改的稿子的人。

无论选哪一种，你都可以对建议标记“同意 / 不同意 / 看不懂”。当你不同意时，Skill 应先理解这句话承载的真实信息或表达边界，而不是强行坚持 AI 的判断。

## 安装到 Codex

在终端执行：

```bash
git clone https://github.com/caiwan-lab/cw-script-redpen.git ~/.codex/skills/cw-script-redpen
```

重新开启一个 Codex 对话后，可以这样开始：

```text
使用 $cw-script-redpen 逐句批改我这篇数据不好的稿子。
```

也可以直接说：

- “我想先拆对标，看看这个方向怎么写”；
- “我已经有稿子，想逐句批改”；
- “这条已经发了但数据差，我不知道该怎么改”；
- “我只有一个选题，想写第一版”；
- “我想盲测一条快发的内容”或“复盘一条已发布内容”。

它会按当前任务追问必要材料，而不是一次性丢给你一张长问卷。每轮开始前会确认：本次目标、已收到材料、仍缺什么、接下来会交付什么。

## 边界

- 使用公开可访问或你自己提供的素材；不要绕过平台权限、登录限制或版权限制。
- 视频下载和逐字稿转写属于独立工作流；本 Skill 分析已提供或已整理的材料。
- 对不同账号、不同题材、不同发布时间的内容，会标注干扰因素，不把相关性说成因果。
- 所有报告以 `CW｜` 作为标识。

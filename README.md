# CW 内容分析工作流

面向内容创作者的 Codex Skill：把“看不懂爆款、不会写稿、发出后不会复盘”拆成一条可重复使用的工作流。

它不会承诺制造爆款。它做的是把高赞与低赞内容、你的真实稿件和发布后的数据放到同一套判断框架里，帮助你知道下一步该改什么。

## 能做什么

### 1. 拆对标

输入你准备写的方向，以及高赞、低赞对标样本。

- 高赞建议至少 5 篇；
- 低赞建议至少 3 篇；
- 从多个高赞样本提取共性，而不是拿单条爆款当公式；
- 用低赞样本做反证；
- 最后把规律转译到你准备写的题材。

### 2. 写稿

如果你已经有原稿，Skill 会基于对标规律做逐句诊断：指出哪句重复了观众已知的痛点、哪句原理放得太早、哪一步仍然太抽象，以及哪些真实表达应该保留。

如果你只有选题，可以选择：

- 直接试写一版；
- 先由 Skill 提问、收集真实经历和素材，再写第一版。

直接试写会明确标记假设和待确认的事实，不会编造个人经历、数据或案例。

### 3. 发布前盲测

对最终稿、封面、标题和时长分别判断：

- 内容成立度；
- 启动与分发潜力；
- 观众分层承接风险；
- 24 小时的条件化数据区间与上下行条件。

它不会把分数合并成“爆款总分”，也不会保证播放或点赞结果。

### 4. 发布后复盘与校准

将发布前判断与真实的 24h / 7d / 30d 数据、评论主题进行对照，区分标题封面、开头、正文交付、观众层级和外部变量的影响。

单条案例只新增记录；同类案例累计足够后，才建议调整规则。

## 安装到 Codex

在终端执行：

```bash
git clone https://github.com/Akumahate11/cw-content-analysis.git ~/.codex/skills/cw-content-analysis
```

重新开启一个 Codex 对话后，可以这样开始：

```text
使用 $cw-content-analysis 帮我从拆对标开始分析这条内容。
```

## 第一次使用

直接告诉 Skill 你当前要推进什么即可：

- “我想先拆对标，看看这个方向怎么写”；
- “我已经有稿子，想知道哪里有问题”；
- “我只有一个选题，想写第一版”；
- “我想盲测一条快发的内容”或“复盘一条已发布内容”。

它会按当前任务追问必要材料，而不是一次性给你一张长问卷。每轮开始前会确认：本次目标、已收到材料、仍缺什么、接下来会交付什么。

## 边界

- 使用公开可访问或你自己提供的素材；不要绕过平台权限、登录限制或版权限制。
- 视频下载和逐字稿转写属于独立工作流；本 Skill 分析已提供或已整理的材料。
- 对不同账号、不同题材、不同发布时间的内容，会标注干扰因素，不把相关性说成因果。
- 所有报告以 `CW｜` 作为标识。
